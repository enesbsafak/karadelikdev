## KaradelikDev 1.4.2

*Türkçe açıklama aşağıda.*

Urgent fix: PHP could not be installed on Windows.

### Downloads

| Platform | File |
|---|---|
| Windows 10/11 x64 | **KaradelikDev-1.4.2-setup.exe** |
| macOS, Apple Silicon (M1/M2/M3/M4) | **KaradelikDev-1.4.2-macos-aarch64.dmg** |
| macOS, Intel | **KaradelikDev-1.4.2-macos-x86_64.dmg** |

From 1.3.x or 1.4.x, use Menu → KaradelikDev → Update; your data folder and settings are kept.

> The Windows installer is not code-signed yet; on SmartScreen's "Unknown publisher" warning choose **More info → Run anyway**.
> The macOS app is not signed with an Apple Developer ID (ad-hoc signature); if it "cannot be verified" on first launch, **right-click the app in Finder → Open → Open**.

### Changes

- **PHP installs work again on Windows**: php.net moved its Windows builds to downloads.php.net and moves older patch releases to an archive, so Quick add and the setup wizard failed with "http status 404". KaradelikDev now picks the current patch of the chosen PHP branch at install time (verified with SHA-256) and falls back to the archive for older branches. Your existing packages list does not need to be edited.
- **Apache keeps installing after new builds**: Apache Lounge only keeps its latest build; the current one is now looked up on its download page.
- **Automatic PHP updates work again**: the update check did not recognize the new version format (for example 8.4.27-1).

### Türkçe

* **Windows'ta PHP kurulumu yeniden çalışıyor**: php.net Windows derlemelerini downloads.php.net'e taşıdı ve eski yamaları arşive kaldırıyor; Hızlı ekle ve kurulum sihirbazı "http status 404" hatası veriyordu. KaradelikDev artık kurulumda seçilen PHP dalının güncel yamasını indiriyor (SHA-256 ile doğrulanır), eski dallar için arşive başvuruyor. Paket listenizi düzenlemeniz gerekmez.
* **Apache yeni derlemeler çıktıktan sonra da kurulabiliyor**: Apache Lounge yalnız son derlemeyi tutuyor; güncel derleme artık indirme sayfasından bulunuyor.
* **Otomatik PHP güncellemesi yeniden çalışıyor**: güncelleme denetimi yeni sürüm biçimini (ör. 8.4.27-1) tanımıyordu.
