## KaradelikDev 1.4.0

*Türkçe açıklama aşağıda.*

Two things PHP developers need every day: **one-click extension installs (Xdebug included)** and **a per-project PHP version in the terminal**.

### Downloads

| Platform | File |
|---|---|
| Windows 10/11 x64 | **KaradelikDev-1.4.0-setup.exe** |
| macOS, Apple Silicon (M1/M2/M3/M4) | **KaradelikDev-1.4.0-macos-aarch64.dmg** |
| macOS, Intel | **KaradelikDev-1.4.0-macos-x86_64.dmg** |

From 1.3.x, use Menu → KaradelikDev → Update; your data folder and settings are kept.

> The Windows installer is not code-signed yet; on SmartScreen's "Unknown publisher" warning choose **More info → Run anyway**.
> The macOS app is not signed with an Apple Developer ID (ad-hoc signature); if it "cannot be verified" on first launch, **right-click the app in Finder → Open → Open**.

### New

- **Install PHP extensions**: Menu → PHP → Extensions → Install extension: Xdebug, Redis (phpredis), Imagick, MongoDB, PCOV, APCu, igbinary. On Windows the official PECL DLL matching your PHP build (version, TS/NTS, VS16/VS17) is downloaded; on macOS it is built with Homebrew PHP's pecl. The extension is enabled in php.ini and checked to load; if it does not, the change is reverted.
- **One-click Xdebug**: Quick settings → xdebug installs Xdebug if needed and enables it with mode = debug, start_with_request = trigger, port 9003.
- **Per-project PHP in the terminal**: inside a project that uses a different PHP version, php, composer and php artisan run with that version and its php.ini, in the KaradelikDev terminal, other terminals and IDEs (once on PATH), Procfile and cron.
- **Command line**: karadelikdev --headless ext-install <name> installs an extension without opening a window.

### Fixes

- The php.ini of a per-project PHP version was only created when its php-cgi pool started; it is now prepared for the terminal too.
- macOS: when Homebrew PHP's extension folder is not set in php.ini (the default), the Extensions menu could miss pecl extensions; it is now read from PHP.

### Development

- Release packages (Windows setup, macOS dmg and update archives) are now built in GitHub Actions by a single workflow (release.yml).
- Extension install and per-project PHP tests run on Windows, macOS Intel and Apple Silicon.

### Türkçe

PHP geliştiricisinin her gün ihtiyaç duyduğu iki şey: **tek tıkla eklenti kurulumu (Xdebug dahil)** ve **terminalde proje başına PHP sürümü**.

1.3.x'ten Menü → KaradelikDev → Güncelle ile geçebilirsiniz; veri klasörü ve ayarlar aynen kalır.

* **PHP eklentisi kurma**: Menü → PHP → Eklentiler → **Eklenti kur**: Xdebug, Redis (phpredis), Imagick, MongoDB, PCOV, APCu, igbinary. Windows'ta seçili PHP derlemesine (sürüm, TS/NTS, VS16/VS17) uygun resmi PECL DLL'i indirilir; macOS'ta Homebrew PHP'nin `pecl install` komutuyla derlenir. Eklenti php.ini'de açılır ve PHP'nin yükleyebildiği denetlenir; yüklenemezse değişiklik geri alınır.
* **Tek tıkla Xdebug**: Hızlı ayarlar → xdebug, Xdebug kurulu değilse önce kurar, sonra `xdebug.mode = debug`, `start_with_request = trigger`, port 9003 ayarlarıyla açar.
* **Terminalde proje başına PHP**: farklı PHP sürümü seçilmiş bir projenin klasöründe `php`, `composer`, `php artisan` o sürümle ve o sürümün php.ini'siyle çalışır; KaradelikDev terminali, PATH'e eklendiyse diğer terminaller ve IDE'ler, Procfile ve cron da aynı sürümü kullanır.
* **Komut satırı**: `karadelikdev --headless ext-install <ad>` eklentiyi pencere açmadan kurar.
* Düzeltme: proje başına PHP sürümünün php.ini'si yalnız php-cgi havuzu başlarken oluşuyordu; artık terminal için de hazırlanıyor.
* Düzeltme (macOS): Homebrew PHP'nin eklenti klasörü php.ini'de yazılı değilse Eklentiler menüsü pecl eklentilerini göstermeyebiliyordu; artık PHP'den okunuyor.
