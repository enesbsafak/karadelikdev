## KaradelikDev 1.4.0

PHP geliştiricisinin her gün ihtiyaç duyduğu iki şey: **tek tıkla eklenti kurulumu (Xdebug dahil)** ve **terminalde proje başına PHP sürümü**.

### İndirme

| Platform | Dosya |
|---|---|
| Windows 10/11 x64 | **KaradelikDev-1.4.0-setup.exe** |
| macOS, Apple Silicon (M1/M2/M3/M4) | **KaradelikDev-1.4.0-macos-aarch64.dmg** |
| macOS, Intel | **KaradelikDev-1.4.0-macos-x86_64.dmg** |

1.3.x'ten Menü → KaradelikDev → Güncelle ile geçebilirsiniz; veri klasörü ve ayarlar aynen kalır.

> Windows kurulum programı dijital olarak imzalı değil; SmartScreen "Bilinmeyen yayımcı" uyarısında **Ek bilgi → Yine de çalıştır**.
> macOS uygulaması Apple Developer ID ile imzalı değil (ad-hoc imza); ilk açılışta "doğrulanamadı" uyarısı çıkarsa Finder'da uygulamaya **sağ tık → Aç → Aç**.

### Yenilikler

- **PHP eklentisi kurma**: Menü → PHP → Eklentiler → **Eklenti kur**: Xdebug, Redis (phpredis), Imagick, MongoDB, PCOV, APCu, igbinary. Windows'ta seçili PHP derlemesine (sürüm, TS/NTS, VS16/VS17) uygun resmi PECL DLL'i indirilir; macOS'ta Homebrew PHP'nin `pecl install` komutuyla derlenir. Eklenti php.ini'de açılır ve PHP'nin yükleyebildiği denetlenir; yüklenemezse değişiklik geri alınır.
- **Tek tıkla Xdebug**: Hızlı ayarlar → xdebug, Xdebug kurulu değilse önce kurar, sonra `xdebug.mode = debug`, `start_with_request = trigger`, port 9003 ayarlarıyla açar.
- **Terminalde proje başına PHP**: bir projeye farklı PHP sürümü seçildiyse, o projenin klasöründe (ve alt klasörlerinde) `php`, `composer`, `php artisan` o sürümle ve o sürümün php.ini'siyle çalışır. KaradelikDev terminali, PATH'e eklendiyse diğer terminaller ve IDE terminalleri, Procfile ve cron komutları da aynı sürümü kullanır.
- **Komut satırı**: `karadelikdev --headless ext-install <ad>` eklentiyi pencere açmadan kurar.

### Düzeltmeler

- Proje başına PHP sürümünün php.ini'si yalnız php-cgi havuzu başlarken oluşuyordu; artık terminal için de hazırlanıyor.
- macOS: Homebrew PHP'nin eklenti klasörü php.ini'de yazılı değilse (varsayılan) Eklentiler menüsü pecl eklentilerini göstermeyebiliyordu; artık PHP'den okunuyor.

### Geliştirme

- Sürüm paketleri (Windows setup, macOS dmg ve güncelleme arşivleri) artık GitHub Actions'ta tek iş akışıyla derleniyor (`release.yml`).
- Platform testlerine eklenti kurulumu ve proje başına PHP testleri eklendi (Windows, macOS Intel ve Apple Silicon).
