## KaradelikDev 1.4.1

*Türkçe açıklama aşağıda.*

KaradelikDev now speaks English out of the box.

### Downloads

| Platform | File |
|---|---|
| Windows 10/11 x64 | **KaradelikDev-1.4.1-setup.exe** |
| macOS, Apple Silicon (M1/M2/M3/M4) | **KaradelikDev-1.4.1-macos-aarch64.dmg** |
| macOS, Intel | **KaradelikDev-1.4.1-macos-x86_64.dmg** |

From 1.3.x or 1.4.0, use Menu → KaradelikDev → Update; your data folder and settings are kept.

> The Windows installer is not code-signed yet; on SmartScreen's "Unknown publisher" warning choose **More info → Run anyway**.
> The macOS app is not signed with an Apple Developer ID (ad-hoc signature); if it "cannot be verified" on first launch, **right-click the app in Finder → Open → Open**.

### Changes

- **UI language follows the system on first run**: Turkish systems get Turkish, every other system English (previously always Turkish). Existing installs keep their chosen language; it can be changed in Preferences.
- **System time zone in php.ini**: new php.ini files use the computer's time zone instead of Europe/Istanbul. Existing php.ini files are not changed.
- **English documentation**: the README is now in English (Turkish in README.tr.md), and the installer descriptions are in English.

---

### Türkçe

* **Arayüz dili ilk açılışta sistemden**: Türkçe sistemde Türkçe, diğer sistemlerde İngilizce (önceden her zaman Türkçeydi). Mevcut kurulumlar seçili dillerini korur; Tercihler'den değiştirilebilir.
* **php.ini'de sistem saat dilimi**: yeni php.ini dosyaları Europe/Istanbul yerine bilgisayarın saat dilimini kullanır. Mevcut php.ini dosyalarına dokunulmaz.
* **İngilizce belgeler**: README artık İngilizce (Türkçesi README.tr.md), kurulum programı açıklamaları İngilizce.
